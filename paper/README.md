# Accompanying Paper

**Title:** Gesture-Based Elevator Control System for Real-Time Floor Selection

**Authors:** Kian Shojaei, Elham Shabaninia

**Venue:** 2025 10th International Congress on Fuzzy and Intelligent Systems (CFIS)

**DOI:** https://doi.org/10.1109/CFIS68949.2025.11652063
