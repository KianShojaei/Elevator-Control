# Dataset

The evaluation dataset used in the accompanying paper contains **70 annotated videos** recorded across four different elevator environments.

It includes single- and multi-digit floor selections, positive and negative floor requests, different cabin geometries and lighting conditions, and gloved-hand samples.

## Sample Dataset

[Download Sample.rar](https://github.com/KianShojaei/Elevator-Control/releases/download/v1.0/Sample.rar)

The sample contains ten randomly selected videos and corresponding label files for inspecting the data format and naming convention.

## Dataset Naming Convention

The paper describes the naming convention as `ExPxAxGN`, encoding the elevator identifier, number of people, digit-length information, target floor, glove usage, and negative-floor status.

For the experimental protocol and evaluation details, refer to the paper in the repository root.
